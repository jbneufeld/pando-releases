Questions

Straight answers.

What is vibe coding, and is Pando for me?
Vibe coding is building software by describing it. You say what should change; an agent in a terminal changes it. Pando is the platform those agents run in: real terminals for every agent you already pay for, routines that run while you are away, a gate on anything irreversible, and one memory they all share. If you direct agents rather than type every line yourself, it is for you.
Do I need an API key?
No. Pando launches the CLIs already installed on your Mac. Sign in to Claude Code, Codex, Gemini CLI, Grok or Ollama the way you always do. Pando never sees a key and never sends a request on your behalf.
What does the approval gate stop?
Anything you cannot take back: deletes outside the project folder, sending messages, deploys, payments. The agent pauses and files a review card that says what it is, what happens if you approve, and what happens if you say no. Approve, say no, or ask for changes in Pando. Nothing else changes while it waits.
Can the agents talk to each other?
Yes. Every terminal in Pando has an inbox. An agent sends another pane a message with one command, and can read what another pane has done. If that pane is idle the message lands as its next prompt. If it is busy, the message waits in a quiet inbox and is read on its next turn. Shell panes only read what they are sent, never run it.
Is Pando Voice included?
Yes. Every subscription includes Pando Voice, the menu-bar dictation app. Hold Right Option, speak, release, and the words are typed where your cursor is. Transcription runs on your Mac with Apple Speech, so it works offline and needs no key.
Which Macs does it run on?
Apple Silicon Macs on macOS 14 or newer. You need at least one agent CLI installed: Claude Code, Codex, Gemini CLI, Grok CLI or Ollama.
What happens if I stop paying?
Your plan renews monthly or yearly, whichever you picked. Cancel anytime from your account and keep access to the end of the period you paid for. Updates are included while the subscription is active. Your Brain is your folder either way.
