One workspace, four agents. Claude Code passes a finding to Codex without you.

Up to 12 terminalsPick 1, 2, 4, 6, 8, 10 or 12 for a workspace. Layout evens out the grid. Save it as a preset and open it in one click.
A different agent in eachClaude Code in one pane, Codex in the next, Gemini CLI, Grok or a plain shell beside them. Each pane can start in its own subfolder.
They hand work to each otherOne agent messages another. The other pane gets it as its next prompt, so you never copy and paste between them.
